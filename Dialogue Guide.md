Hello, Archie devs, modders, and curious players!
In this guide, I'll explain how to use the Dialogue System and NPCs. As of right now, this system is in beta. This means that it is still a work in progress, as is the rest of Archie(and the ACE2D engine/framework in general). When new features are added, this guide will be updated along with it.
Note: this guide assumes you already understand how to add objects to a level's layers(guide for that coming soon!).
First, let's get your NPC out of the way! We need ASSETS, first. To start, make a new folder in assets/npcs to hold them(we'll call this their sprite directory). Next, make their base design. While you might want to give your character a smile, start with a neutral expression on their face! Save this into the folder as "base.png." Then, change it to a smile. Save this as base-smile.png. Finally(at least for the regular expressions), make a frowning one, and save it as base-frown.png.
Next, add a subfolder to their sprite directory called "talk." For each of the base sprites, modify their face to look like they're talking. Then, save these new ones into the talk folder. You should have talk, talk-smile, and talk-frown. You can add more expressions if you want, but make sure that you name them "talk-[expression]" in the files. Plus, be careful later when you're coding to not accidentally try to assign an expression to a character that doesn't have it.
Now, to make your NPC object. Simply make sure the file you're working in has TalkNPC imported from classes.TalkNPC, and then make a TalkNPC object. Specifically, "TalkNPC([character's dialogue, a Dialogue object, which we'll cover later],[x],[y],[width(used only for hitbox right now)],[height(see note for width)],[the name of the NPC's sprite directory])." Optionally, you can specify their starting expression as a kwarg with the parameter name "emotion." This object goes into the "npcs" layer.
Now, for the Dialogue object. A Dialogue object currently has only one required argument: a string with their text. There are some things you can do with this. First off, to separate dialogue into separate boxes, use \r. Then, there are special characters. These are formatted as a null character(\0) followed by another character to specify the function. For example, want someone other than the NPC(most likely the player, as there is currently no way to make another character play their talking animation, and there are only stationary NPCs so far anyway) to speak the next line? Well, here's an example of how to do that!
"Archie\0s: Hi, I'm Archie!"
As you can see, we use a \0s to indicate the speaker has just been listed. "s" stands for speaker. If there is a speaker specified, no matter who, NPCs will by default not play their talking animation. It is planned to make it so you can specify an NPC's "Speaker name" so you can have them speak with a name listed.
There are currently three other special characters, all related to the NPC's facial expression.
\0| triggers a neutral expression,
\0( triggers a frown,
and \0) triggers a smile.
That's basically all for now. See you later!
