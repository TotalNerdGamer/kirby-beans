A game our company(read: friend group in an MS Teams community) has been designing for years(read: we came up with it in third grade during virtual and we've just now started it back up)!

<h1>Basic Game</h1>
Archie: Of Mice and Men is a simple 2D platformer made in the ACE2D engine, an engine that was made for this game, but conceivably could be used for others. Honestly, the "engine" is only really that good for Archie games, because if you want to make new enemies, hazards, or mechanics, you'll have to code them yourself. But you can make levels without too much difficulty! And platforms and collision are already handled for you. :)

<h1>Installation</h1>
If you're reading this, you've almost certainly downloaded and likely unzipped the game already. If you haven't already, extract the files.
Then, you can run "run.bat" or "run.sh" if you want. These will auto-install pygame-ce for you. However, I recommend, if you know how, opening a terminal, navigating to this folder, making sure you have pygame-ce, and then using python to run the Archie.py file in ./main, but DON'T navigate INTO that folder - it won't be able to access the files it needs!

<h1>How to Play</h1>
Archie is a simple game: W to jump, A & D for left and right(respectively), and Z or Enter to talk to NPCs and read signs!
